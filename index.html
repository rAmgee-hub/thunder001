추정 시세는 불러온 거래 데이터에서 같은 이름 아이템의 급-가격 관계로 계산해요. 거래 기록이 없는 장비는 '-'로 표시되고 합계에서 빠져요.

API 키를 발급한 넥슨 계정의 캐릭터만 불러올 수 있어요. 키는 "내 캐릭터 장비 가치" 탭의 입력값이나 로컬 서버의 .env를 사용해요.
